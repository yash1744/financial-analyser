I want to add an LLM chat backend that uses these tools.

Goal:

Frontend sends a natural language message:

"Why did I spend more this month?"

Backend:
1. Receives message.
2. Sends it to LLM with available finance tools.
3. LLM decides which tools to call.
4. Backend executes tools.
5. Tool results are sent back to LLM.
6. LLM generates final natural language response.
7. Backend returns/streams response to frontend.
